# StepMark 下一阶段外部证据与模型验证计划（2026-11-13）

> 范围：研究与验证路线；本文件不代表已执行下述新数据集的统计检验，不授权重用受限制的测试题材，不更改线上评分政策。
> 仓库现有已执行的习惯、BFI 数据基准及其局限，见 [DATASETS_AND_VALIDATION.md](./DATASETS_AND_VALIDATION.md) 和 [RESEARCH_AND_FORMULAS.md](./RESEARCH_AND_FORMULAS.md)。

## 1. 现有证据的边界

- `packages/core/src/habit-progress.ts` 的 `habit-progress-v1` 是版本化视觉启发式：`100*(1-exp(-n/55))`、`0.45/0.55` 混合权重、证据上限和复查间隔都不是临床/心理计量学标定参数。不得以“养成概率”“有常模的自动化评分”呈现。
- 2026-11-12 已完成独立 GitHub Actions 研究作业：Fiorella 2026（175 人/9416 日记），Edgren 2025（194 人/16490 个研究日），Edgren 2026 RCT（313 人/26605 个研究日），以及 `psych::bfi`（2800 人）。各作业的通过只证明对应脚本正确执行并输出了所报告的指标，**不是** StepMark 产品预测有效性的证据。
- Fiorella 的时间留出预测比较对不同自动性量表给出不同排序。仅在同一可拟合参与者子集上比渐近模型与最后观测值：四题平均 13.857 vs 13.688、两题平均 11.377 vs 13.808、单项 16.561 vs 14.548（归一化 RMSE，越低越好）。不得跨不同测量版本直接合并参数或按测试集选模。
- `logic-a-v1`/`logic-b-v1` 目前各 6 题，为未等值的原创测验；题数小且未通过 IRT 实证标定。报告原始作答差异即可，不能据此断言潜在推理能力提升。

## 2. 新核实的研究依据

### 2.1 低负担习惯自动化指标

Gardner, Lally & Rebar (2024), “Can—and should—automaticity be self-reported using a single item? A secondary analysis of 16 datasets”, https://pubmed.ncbi.nlm.nih.gov/39324279/ 。

该文分析了 16 个数据集、16,838 人、7 类行为，认为在需要简短量表的场景，一项“行为 X 是我自动做的”可作为四题 SRBAI 的实用替代之一。**不是**允许将任何 AI 推断的“感觉”标签等同于该题，也没有证明单题能计算准确的“习惯完成百分比”。

Gardner, Phillips & Judah (2016), https://pubmed.ncbi.nlm.nih.gov/26991427/ ：区分行动的自动**启动**与自动**执行**；前者对行为发生的预测更相关。StepMark 优先收集/识别用户对**启动是否不费思考**的明示描述，而不是笼统问“做起来熟不熟练”。

### 2.2 情境线索与重复

Zhu et al. (2026), “Not all cues are equal”, https://pubmed.ncbi.nlm.nih.gov/42586550/ ：14 项独立研究、6069 人的元分析，情境一致性与身体活动频率相关 `r=0.11`，与习惯强度相关 `r=0.20`，均为相关性、并非因果效应或可直接用于产品评分的权重。时间/日常流程线索尤其值得在独立效标中检验。

Fiorella (2026), https://doi.org/10.1007/s10648-026-10235-3 ：当天情境一致性与当天自动感有关，但前一报告的情境一致性在控制历史自动感和重复后，并未可靠预测随后自动感（报告 `p=.651`）。因此不得把“情境一致”设计成自动加分的确定规则。

**建议的事件语义**：`cueEncountered`（是/否/未知）、`eligibleOpportunity`（是/否/未知）、`performed`（是/否/未知）、`initiationAutomaticity`（带量表版本的本人报告）、`executionAutomaticity`（可选）、`contextKind`（可选）、`evidenceSource` 和观测时间。未知绝不编码为失败；AI 仅能基于明确措辞提取，不能编造历史。数据库迁移必须独立评审、保留旧数据与租户隔离。

## 4. 统一验证门槛（按本仓库“科学可信度”目标）

### 数据准入

每个基准单独记录：原始发行方、文章 DOI、数据字典、文件版本/不可变 SHA-256、数据许可与独立题材许可、允许的使用方式、观测粒度、测量工具版本、缺失含义、是否与 StepMark 原有题目同构。

CI 脚本在临时 runner 中下载，只输出汇总统计，严禁将第三方个人原始记录、正文和作答明细写入 Git、生产数据库或 Actions 日志；无法确认许可/题意/校验和时拒绝继续。

### 数学与实验设计

1. **先定预测目标**：比如“下一次有合格线索时是否自主启动”“下一周有独立测量的自动感等级”，不要把 SRBAI、出勤、行动成功率混为一个真值。单题有序响应优先用有序分类模型；适用时可报告 Brier/对数损失/有序评分，避免把 0–100 UI 指标直接当概率。
2. **基线优先**：上一次观察、个人训练均值、简单回归、渐近曲线、分层模型按相同受试者、相同未来日期和相同测量版本比较。比较真正的样本外 MAE/RMSE；进阶模型必须超过简单基线才值得发布。
3. **防止泄漏与选择偏倚**：按参与者隔离开发集与最终独立测试集，开发集内按时间前推调参；同一个参与者的未来作答绝不能进入训练。参数选择和试验阈值提前冻结，不得从最终测试集反复选“最好”的模型。
4. **不确定性与缺失**：以参与者为单位配对 cluster bootstrap 计算改进幅度的区间；报告可拟合/不可拟合人数、有效预测条数、按习惯类别与测量版本分层结果。做 MAR 与保守 MNAR 敏感性分析；缺报不能等于“没有线索/没有执行/自动感为零”。
5. **迁移与公平性**：检验语言、题材、平台、年龄、时间、练习暴露、主观与客观测量版本的误差漂移。信度 `Cronbach α`/ω 不能单独证明效度；2PL 的 item information 不是自建试题的实证标定。
6. **验收**：明确输出 `passed_methodology`、`insufficient_evidence`、`failed_external_validation`，保留机器可读 manifest 和聚合评估；仅在原始数据、代码、对照、权利、区间全部可重现时才允许“已在某数据集上通过预测检验”。即使通过，也不得写成“普遍适用于所有用户”。

## 5. 具体执行顺序

**P0：完善可重复验证基础。** 给当前 Fiorella/Edgren 时序结果增加相同受试者的配对误差区间、缺失分层以及固定基准比较；在 CI 里加入负向对照，确保真实外部试验数据的观察指标不被误认为 StepMark 能力/习惯进度的真值。此阶段只动离线研究代码与文档，不调整线上分数。

**P1：认知测评算法实证检查。** 从 ICAR/IRW 的二元正确性数据入手，在检查官方转换与权利之后分受试者训练/验证 1PL/2PL；固定校准参数，对新的受试者作答比较预测对数损失、Brier、标准误覆盖率和数据稀疏性；检查 DIF/群体稳定性。结果**仅证明算法实现可复用**，不能让 StepMark 原创 A/B 卷自动获得常模。

**P2：表达能力子任务。** 建立作文论证结构与人工质量分分开的任务：前者用 PERSUADE，后者用 ASAP 2.0；报告不同题目、长度段和语言/受试者群体的公平性差异。初版只展示“在已验证子任务上的证据”，不生成一个貌似客观的通用表达智商。

**P3：轻量习惯追踪语义升级。** 经迁移设计和 UI 审核后，优先使用用户在聊天中明确给出的线索、行为、自动启动感受；无需每次填写问卷。用户沉默或 AI 无法判断时保持未知，并建议低频复查，不惩罚用户。单题自动感优先作为**直接观测维度**，复合 0–100 仅保留标为“探索性”的展示。

**P4：本项目原生验证。** 在没有合法的独立原生作答标定样本前，继续如实展示“未校准”“缺乏证据”；不得把外部研究中其他题目的参数填入自建 A/B 题或宣称真实用户的能力成长得到了证明。

## 6. 不做的事情

不直接拟合“完成 90 次就养成”的统一阈值；不混合习惯形成与有害习惯衰退的参数；不把 AI 自述理解当 SRBAI 正式答案；不把英文作文评分当中文口语分；不把 BFI 性格问卷当思维测验；不将 Metaculus API 或 ICAR 受限制题材未经许可放入应用。

**本次修订状态**：新文献和公开数据来源已核查，尚未运行 ICAR、ASAP 2.0 或 PERSUADE 的真实数据评估；因此没有为这些新数据集报告任何拟合结果或能力效度结论。
