The committed CSV contains aggregate statistics from a fixed five-participant convenience subset of Fluhr, Timokhov & Nebe, *learning-habits*, OpenNeuro ds008039 v1.0.0, DOI https://doi.org/10.18112/openneuro.ds008039.v1.0.0. Upstream data are CC0 1.0 (https://creativecommons.org/publicdomain/zero/1.0/); source files, revision and Git blob SHA-1s are listed in the manifest. The aggregate is a transformation, not an upstream full-cohort release. No trial-level, identifying or imaging data are in this folder. Do not apply the project Apache-2.0 license to third-party datasets. Do not conflate availability, license verification, byte verification, and scientific validation. Other sources in the catalog have NOT been downloaded in this update unless their status explicitly says otherwise. Existing older executed datasets are listed separately in the historical document.
