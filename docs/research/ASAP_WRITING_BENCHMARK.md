# StepMark P2: ASAP 2.0 英文写作质量离线验证

**性质：研究代码，非正式能力测验，不是已经验证的中文表达能力得分。**

- 原始发行方：Scott A. Crossley 等，ASAP 2.0，论文 https://doi.org/10.1016/j.asw.2025.100954 ，数据仓库 https://github.com/scrosseye/ASAP_2.0 。

- 仅使用**作者提供的训练集 ZIP**。从中重新进行内容哈希固定划分；没有读取另行密码保护的官方测试集，不能声称通过官方独立测试。
- 只将英文短文、匿名作文编号、题目名称和人工质量评分读入一次性 Actions 研究进程。不会输出短文原文、逐篇预测、身份信息，研究数据不上传 Git、生产服务、用户数据库或第三方模型 API。

## 评价目标与模型

任务是预测**相同试题分布下英文中学生议论文的人工整体质量评分**，不是母语、年龄、场景不匹配的中文表达、口语沟通或语言天赋评分。

预先确定三种离线对照：

1. **每个题目的训练集平均分**：一个很简单、但不能省略的基线。
2. **长度 + 题目标识 Ridge 回归**：检验篇幅和任务差异能解释多少人工分数。
3. **长度 + 题目标识 + TF-IDF 词和二元词组 Ridge**：可重复的文本特征模型，而不是对大模型评分能力的宣称。

在从训练集固定按规范化短文内容 SHA 划分之后，才拟合向量化器和回归器。重复文本不得跨集合，留出集全部用同一组样本。主要指标为 MAE、RMSE、与题目均分基线的配对绝对误差改进和 1200 次行级 Bootstrap 百分位区间。按题目和文章字数三分位报告差异；并说明作文行不是已验证的独立写作者，Bootstrap 不应被当作严格的人群不确定性。

对每种预测分值限制在数据所定义的 1–6 分范围。若官方原始资料出现不同评分范围、模式、样本规模或源 ZIP 校验不一致，必须人工审核，不准默默改规则。

## 局限与下一步

- 数据来自美国中学生的英文写作，不是中国成人表达，也不是口头表达。
- TF-IDF + Ridge 是公开的传统机器学习特征模型；能预测人工整体评分不等于能识别论证结构，也不等于 AI 评语准确。
- 更高质量文本并不一定更长；需要分题目对比长度基线防止算法只奖励篇幅。
- 本阶段**没有**跨全新题目、跨语言、跨人群或重复测量进步的独立实证效度。
- 论证结构是单独的任务：PERSUADE 2.0 作者完整数据在 https://github.com/scrosseye/persuade_corpus_2.0 ，官方 README 明确为 **CC BY-NC-SA 4.0**；不能套用 PERSUADE 一般页面的 CC BY 4.0 做商业训练。只允许遵守许可的研究用途，且不得将第三方数据并入 StepMark 正式模型。
- 后续需要人类标注对照、中文表达新数据与受试者许可，方可评估线上 StepMark 表达能力量规。
