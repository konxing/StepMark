# StepMark P2：公开写作与论证结构数据的真实验证结果（2026-11-13）

> 研究结论：**离线方法有数据支持；不足以将模型用作正式的个人表达能力评分**。ASAP 2.0 和 PERSUADE 2.0 测量目标、许可条件和数据来源均不同，不能合并训练集、把指标合并成一个“表达能力分”。

## A. ASAP 2.0 人工整体写作评分

作者原始来源：https://github.com/scrosseye/ASAP_2.0 （CC BY 4.0）；论文 https://doi.org/10.1016/j.asw.2025.100954 。

已完成真实研究运行：https://github.com/konxing/StepMark/actions/runs/43266684235 。

- 读取了原始发布方 **训练集** ZIP，固定 commit `060ab225ca0984c0bf43ff222bf6bb2bc6195b6f`、Git blob SHA1 `a6d7534bfd6733f056b571b0c459280e31430c45`，11,240,696 字节；
- 原始训练集有 **17,307 篇作文 / 7 个题目**；对规范化文章内容做固定哈希分组，得到训练 **13,749 篇**、留出 **3,558 篇**。完全重复文章不跨集合。
- 留出集文章对应人工整体评分为 1–6，研究不涉及官方另一个密码保护的测试集。离线候选使用训练集题目平均分、长度 + 题目标识 Ridge、文本 TF-IDF + 长度 + 题目标识 Ridge。

| 模型 | 留出 MAE↓ | 留出 RMSE↓ | 相对题目均分 MAE 改善↑ | 配对 Bootstrap 95% CI |
|---|---:|---:|---:|---|
| 题目均分 | 0.791949 | 1.013482 | 0 | - |
| 只使用长度 + 题目 | 0.558924 | 0.724132 | 0.233024 | [0.213940, 0.250305] |
| TF-IDF + 长度 + 题目 | **0.490162** | **0.633722** | **0.301787** | [0.283592, 0.319441] |

**额外检验：在已经考虑长度和题目之后，文本特征的 MAE 额外改善为 0.068762，配对 95% Bootstrap 区间为 [0.062792, 0.075246]。** 即，这个模型不只是学会了“文章越长得分越高”；但即使模型在这组英文中学生作文上预测较准，也不等于学会了具备可解释性的论证评分规则。

不同题目的文本模型 MAE（固定留出作文）：`Car-free cities 0.579290`，`Does the electoral college work? 0.580625`，`Driverless cars 0.446372`，其余四题为 0.440390–0.504964。表现明显因题目而异，不能忽略题目迁移误差。

## B. PERSUADE 2.0 论证单元分类

官方论文 https://doi.org/10.1016/j.asw.2024.100865 ；作者仓库 https://github.com/scrosseye/persuade_corpus_2.0 明确使用 **CC BY-NC-SA 4.0**（不可商业使用）。实际研究子集采用 https://github.com/HakeoungLee/edis8100-datasets ，固定 commit `6386a0de8d8f3f3bb3bfa7f3e0cc53ab7cc9dc3d` 的四题教学整理版，Git Blob SHA 检验压缩包。绝不转用于正式网站数据库或商业模型训练。

已完成研究运行：https://github.com/konxing/StepMark/actions/runs/43266694370 。

- **5,531 篇作文，63,211 条标注片段**，其中 412 条没有可用文本，被明确排除；符合条件 **62,799** 条。
- 按作文和规范化全文哈希分组，训练 **50,061 条**，留出 **12,738 条**、覆盖 **1,128 篇**作文。**绝不按片段随机分配**同一作文的不同片段到训练和留出集。
- 任务是论证片段的 8 类人工标签（Lead/Position/Claim/Counterclaim/Rebuttal/Evidence/Concluding Statement/Unannotated）的分类，不是人类作文整体质量分数。

| 模型 | Accuracy↑ | Macro-F1↑ | Weighted-F1↑ |
|---|---:|---:|---:|
| 各题最常见类别 | 0.304129 | 0.058301 | 0.141849 |
| 题目 + 片段长度 | 0.556759 | 0.251558 | 0.460843 |
| TF-IDF + 题目 + 长度 | **0.675381** | **0.514691** | **0.644249** |

**直接比较文本 vs 仅长度的准确率改善：按片段计 +0.118621，按每篇作文等权为 +0.122466；作文聚类 Bootstrap 95% CI 为 [0.115177, 0.130031]（每篇作文等权）**。不要把不同权重的中心估计和区间混用。

### 不可掩盖的弱项

- Evidence 的召回约 **86.46%**、Claim 约 **82.89%**；
- **Counterclaim 仅 13.93%，Rebuttal 仅 6.18%**，说明模型非常不适合对用户宣称能可靠找到反论点、反驳质量；
- 跨题目宏 F1 分布：`Cell phones at school 0.4631`、`Distance learning 0.5601`、`Does the electoral college work? 0.5050`、`Driverless cars 0.4656`，误差存在题目差异。

**产品政策：不向用户显示“反驳能力准确量化”或用此模型做后台人能力加分。** 后续应设计类别平衡、少数类召回与错误代价的研究实验，并使用独立的新留出集验证；不能只在本次相同测试集迭代调到得分最好就称模型科学有效。

## C. 本轮没有改变的事项

- 原始作文和个人作答不提交到仓库、日志或数据库；Actions 仅报告聚合统计。代码和数据许可分开管理。
- 没有向线上 StepMark 部署 TF-IDF 权重或生成式 AI 评分器；没有给中文成年人设置“表达能力百分比”，也没有使用任何心理学常模对用户排序。
- 研究尚缺作者级别独立样本划分（同一作者可能提交多篇作文）、跨全新题目的外推、中文语料、人工盲评对照、可解释性与公平性审核。
- Bootstrap 为事后探索性分析，未针对多种模型和指标进行多重比较调整，不应成为对人心理能力的断言。

## D. 可执行下一阶段

P2 的“公开数据来源验证、样本外对照与弱项识别”已完成，**生产评分准入未通过**。应先：
1. 保持英文作文整体评分与人工论证标签两条数据流隔离；
2. 针对 Counterclaim/Rebuttal 的低召回设计更可靠的标注模型，预先冻结新验证指标与测试集；
3. 搜集有明确合法再利用许可、中文成人写作与口头表达任务的人工评分数据；
4. P3 习惯模型只先增加研究层的线索/机会/实际执行/自动启动感“四态语义”与测试，不先动生产库或自动给用户“养成概率”。
