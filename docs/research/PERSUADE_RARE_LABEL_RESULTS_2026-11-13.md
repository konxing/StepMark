# PERSUADE 2.0 四题跨题目少数类别验证：实证结果（2026-11-13）

**状态：已在独立 GitHub Actions 使用经 SHA 固定的真实公开数据成功执行。** [查看工作流](https://github.com/konxing/StepMark/actions/runs/43268859471)。

**许可约束：PERSUADE 2.0 原作者采用 CC BY-NC-SA 4.0。下述数据和模型都仅供非商业研究；不准并入正式商业产品训练、能力评分或数据库。** 具体方法、来源、版本、训练前固定的参数和设定见 [设计文档](./PERSUADE_RARE_LABEL_LOPO.md)。

## 验证设计

- 采用经独立校验 Git blob SHA 的四题教学子集，5,531 篇作文、62,799 条有效论证片段。
- 四轮 **leave-one-prompt-out**：每轮完整留出一篇作文题目，其余三个题目训练；不使用目标题目的标签、文本词频或题目标识进行训练。每条样本仅被测评一次。
- 预先固定 `unweighted`、`sqrt_capped`、`balanced` 三个实验模型，差异仅在训练阶段的类权重。全部模型照实报告，不按留出测试集选择“赢家”。
- 同一作者在不同题目间可能重复出现，单篇标签本身也可能有多种可接受解释。此实验既不是新的完全独立研究队列，也不是 StepMark 用户心理测量校准。

## 四轮汇总结果（每条片段只算一次）

| 训练类权重 | Accuracy | Macro-F1 | Counterclaim P / R / F1 | Rebuttal P / R / F1 |
|---|---:|---:|---|---|
| 不加权 | 0.598131 | 0.403946 | 0.597741 / 0.224177 / 0.326066 | 0.341844 / 0.108804 / 0.165068 |
| 平方根温和加权，限制 0.5–3.0 | 0.597939 | 0.439390 | 0.574742 / 0.217986 / 0.316088 | 0.260230 / 0.295711 / 0.276839 |
| 反频率完全平衡 | **0.608354** | **0.475196** | 0.432556 / 0.338547 / 0.379821 | 0.204048 / 0.277652 / 0.235227 |

**直接结论：**完全平衡获得本次最高的整体 Macro-F1 和 Counterclaim 召回，但对 Rebuttal 的 precision 仅约 20.40%，误报很高。温和加权让 Rebuttal 召回更高（29.57% 对 27.77%），但准确率、精确率等必须一并比较。三种算法都**没有通过**预先设立的两个少数类别 precision 和 recall 均达到 0.5 的诊断守门条件。

## 按独立留出题目差异

| 完全留出的题目 | 不加权 Macro-F1 | 温和加权 Macro-F1 | 完全平衡 Macro-F1 |
|---|---:|---:|---:|
| Cell phones at school | 0.373474 | 0.478202 | 0.515193 |
| Distance learning | 0.419172 | 0.444879 | 0.446130 |
| Does the electoral college work? | 0.404008 | 0.416692 | 0.478473 |
| Driverless cars | 0.370734 | 0.413377 | 0.454769 |

题目间差异显著，说明在一种题材上做出漂亮指标不足以保证跨题材可靠。尤需关注“反驳”和“反论点”的表达方式随题目与写作提示发生变化。

## 允许/禁止的下一步

- **允许：**在隔离的非商业研究流程中继续比较不同标注体系、跨题目验证和标注者一致性；固定训练/验证/独立测试策略；记录少数类的误报与漏报成本。
- **禁止：**因为 `balanced` 的 Macro-F1 较高就把它直接用于 StepMark 正式表达能力评分；未经许可把 PERSUADE 2.0 权重、样本文本或标注数据迁入公网产品；把单个论证标签预测准确率宣称为用户的批判性思维能力。
- **未来真正的评分准入：**合法可用、覆盖成人中文表达的人工标注数据，明确评分类目，跨参与者/题目/时间独立外部测试，可靠性和分人群误差评估，错误可追溯与申诉机制。

这次测试说明：**类不平衡确实影响识别性能，使用训练集类别权重有价值，但关键少数类仍未达到值得可信托付的质量。**
