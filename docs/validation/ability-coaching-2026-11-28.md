# 从初测到训练习惯再到独立复测

## 当前可用的闭环

1. 完成逻辑推理 A 卷后，控制台展示条件推理、论证与证据、数量与比例各自的答对数和题数。两道题只能提供练习方向的线索。
2. 选择训练方向并生成方案。配置服务商后，AI 是主要入口。服务商只收到所选训练方向、该方向的答对数和总题数。AI 拟定一次短练的动作、触发情境、最低完成动作和可观察的验收标准。分数解读和示例由程序提供。服务不可用时仍能用内置方案。
3. 确认后保存并关联到逻辑推理。每次机会可记录完成、漏做或当天没有触发。本人自评和 AI 的文字标注分别呈现。界面并列显示累计执行、自评天数和产品内的习惯进度。
4. 至少 7 天后可打开 B 卷。控制台呈现 A/B 原始表现，并统计初测完成和习惯关联之后、B 卷第一题之前的完成次数。习惯执行反映练了多少，复测反映新题上的表现。目标题目和练习题来自独立题库。

## 可以解读的数字

| 数字 | 含义 |
| --- | --- |
| 各方向答对数 / 题数 | 当次独立短卷上该方向的原始表现。每方向只有两题，选练习时可参考。 |
| A/B 原始得分差 | 两份短卷的答对比例之差。公开短卷还需要等值、测量误差和练习效应证据，才能估计可靠能力变化。 |
| 完成数 / 有效机会数 | 已记录的执行情况。没有触发和未记录的日期不计入分母。 |
| 习惯进度与自评天数 | 产品反馈结合执行和本人的启动感受。AI 对自由文本的解释不计作本人自评。 |

表达结构、注意控制、预测校准仍处于现有项目的研究范围。每项要进入能力量化需先界定要测的行为、预设评分规则，采集独立复测和不同任务上的证据。开放任务可先用 AI 给出有依据的定性反馈，并保留原始作品供人复核。

## 依据

- 给习惯指定可识别的情境和小动作。执行率与自动性分别采集，个人形成速度可以不同。[实施意图实验](https://doi.org/10.1037/0022-3514.73.1.186) · [Lally 等实地研究](https://doi.org/10.1002/ejsp.674) · [自评自动化量表研究](https://doi.org/10.1186/1479-5868-9-102)
- 用新题检查表现，后续需要独立样本估计题卷、顺序和重复练习的影响。已有研究发现交替使用新题可以在部分任务上减少练习效应，跨卷量尺仍需检验。训练结果也需要在独立任务上检查迁移。[Beglinger 等的复测研究](https://pubmed.ncbi.nlm.nih.gov/15896564/) · [Gross 等的跨卷等值研究](https://doi.org/10.1080/13803395.2012.681628) · [Owen 等的训练迁移实验](https://kclpure.kcl.ac.uk/portal/en/publications/putting-brain-training-to-the-test/)
- 练习建议从具体表现出发，给一项可执行的下一步。示例由程序固定，避免把临时生成的论证当成标准答案。[Shute 的形成性反馈研究](https://doi.org/10.3102/0034654307313795)
- 开源实现可参考 jsPsych 的浏览器实验流程和数据记录，以及 Loop 的历史和执行视图。本次继续使用 Stepmark 原创题。jsPsych 采用 MIT，Loop 采用 GPL v3 或以后版本，ICAR 项目当前公开说明对在公开产品页面分发原题有限制。[jsPsych 许可证](https://github.com/jspsych/jsPsych/blob/main/license.txt) · [Loop 许可证](https://github.com/iSoron/uhabits/blob/dev/LICENSE.txt) · [ICAR 项目说明](https://sms.statistik.tu-dortmund.de/en/research/projects/completed-research-projects/international-cognitive-ability-resource-icar/)

## 验证

自动化测试覆盖不完整或无法核验的初测、仅发送必要分数摘要、AI 返回格式异常时的回退、关联习惯的并发重试、复测前执行次数，以及账号之间无法读取彼此记录。测试使用独立 PostgreSQL 和合成账户。

真实 DeepSeek 测试为每个训练方向分别提供 0/2、1/2、2/2，共 9 组合成输入。早期版本曾把两道题解释为水平稳定或起步。正式版本由程序解释答对数并提供审核过的示例，服务商附带的额外字段不会进入建议或记录。最终 9 组均返回可解析的 AI 草稿，训练方向、时长范围、显示的答对数及固定示例全部符合约束。后续仍需用实际使用记录检验训练是否能提高独立任务表现。
